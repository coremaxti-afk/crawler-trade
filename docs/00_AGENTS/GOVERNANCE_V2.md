## Objetivo

Reduzir sobrecarga de contexto.

- Chat → Comunicação Executiva

## Princípio Fundamental

Chat deve conter:

- decisões;
- aprovações;
- direcionamentos;
- coordenação.

GitHub deve conter:

- documentação;
- relatórios;
- metodologia;
- resultados;
- especificações
